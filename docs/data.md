# 掲載データと出典の扱い

ガイドに載せる情報はすべて `db/data/` の JSON にあり、出典と確認日を記録しています。

## ページ構成・住所・ナビゲーション

読む画面はヘッダーのメニューで「宮崎の地図」「開催・アクセス」「ごはん・人数」「過去RubyKaigi」の4ページに分かれ、1画面に1つの話題だけを表示します。各ページは Rails のルート（`/event`、`/restaurants` など）で、URL を共有・リロードしても同じページが開きます。Rails の生成は起動時の1回だけで、ページ切り替えで Wasm を再起動しません。モバイルは開閉式メニューで、Escape・リンク選択・履歴移動で閉じます。掲載年の公式サイトへの外部リンクもヘッダーに配置しています。

飲食店20件は一覧／地図を同じ人数・住所の町名フィルターで切り替えます。地図では確認済み全20地点を残し、条件外を淡色表示します。重なるピンは候補選択でも選べます。ホテルや商業施設のピンは建物代表点で、入口・階数の位置・安全な乗降場所を示しません。地図は選択時だけ読み込み、一覧に戻ると破棄します。追加のRailsリクエストやWorker起動はありません。

飲食店20件と元の7地点に名称・住所コピー、Google Maps検索、徒歩・車ルートのリンクを表示します。このアプリから閲覧者の現在地を取得しません。出発地はGoogle Maps側で選びます。バス停・交差点・繁華街は周辺／エリアの参考住所として明示し、宮崎神宮駅と文化公園前の住所はYahoo!マップの補助出典であることを表示します。

写真は公開サイトに載っているだけでは転載しません。今回、配信可能な実画像まで確認できた素材はないため、全件に「写真未掲載」の非写真サムネイルを使っています。架空の店舗写真は生成していません。

Google Maps URL形式: https://developers.google.com/maps/documentation/urls/get-started 。地図とコピー・メニューの繰り返し操作、背景タイル失敗時、現在地API不使用、Worker解放維持は `tests/dining-navigation.mjs` で検証します。

## 地図で読む宮崎

大きな2D地図と地点カードで「宮崎に着く」「会場へ行く」「夜の街へ」を切り替えます。`GET /map/scenarios/arrival|venue|night.json` はブラウザ内の Rails が処理し、同じ絞り込み済みデータから ActionView ERB のカードと GeoJSON を返します。地点をクリックするとカードも連動します。

- 地図：Leaflet 1.9.4 と地理院タイル（淡色地図）。WebGL・APIキー・現在地取得は使いません
- 地図の出典表示と重ね合わせの説明を画面内に表示します。タイルをまとめて保存する機能やオフライン一括取得はありません
- 模式図の線は地点を結ぶ概略線です。道路形状を表しません
- 正確な地図では「徒歩／車」を切り替えると、OpenStreetMap の道路に沿った経路（車は実線、徒歩は点線）と距離・時間の目安を表示します。経路は `scripts/generate-map-routes.mjs` が FOSSGIS の経路検索（routing.openstreetmap.de、openstreetmap.org と同じ）で事前に計算し、`db/data/map_routes.json` に出典つきで保存したものです。閲覧時に経路検索 API は呼びません。地点や導線を変えたら、このスクリプトを再実行してください
- 経路の距離・時間は目安で、公式の所要時間・乗り場を優先します。バス区間は車の道路で代用しており、実際の運行経路ではありません。ライブ交通・徒歩圏半径は表しません
- 同じ経路を「Googleマップ」リンクで開けます（出発地・経由地は固定の地点で、閲覧者の現在地は使いません）。経路データ：© OpenStreetMap contributors（ODbL）
- 7地点の座標・出典・代表点としての精度は `db/data/places.json`、見方ごとの導線は `db/data/map_scenarios.json` に記録します
- 駅は施設代表点、文化公園前はバス停周辺、橘通り3丁目は交差点・乗換エリアの参考点です。乗車方向別の停留所位置は断定しません
- ニシタチは地元団体の公開マップ78地点の座標中央値から求めた参考点です。公式の境界や特定店舗を意味しません
- タイルが読み込めない場合も、同じ Rails 生成の地点カード・移動説明・公式出典を読み続けられます

地図の資料： https://maps.gsi.go.jp/development/ichiran.html / https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html 。国土地理院の背景地図に独自の地点・概略線と OpenStreetMap の経路を重ねたもので、国土地理院作成の移動案内ではありません。

地図のブラウザ検証： `node tests/map.mjs`（Chromium / WebKit、3つの見方、カード連動、タイル読込失敗時のテキスト継続）。

## ごはんと人数・過去の開催

`db/data/restaurants.json` は2026年10月8日に確認した公開情報です。20件（飲食店16店・ホテル宴会場4施設）の総席数と宴会・着席予約上限を分けています。元の私的な会議記録や担当者情報は含めていません。

実物の Rails が JSON を読み、同じデータを `/restaurants.json`・`/archives.json` と ActionView ERB のカードに出力します。人数フィルターは既に生成したカードの宴会・着席予約上限だけを参照し、総席数から推定しません。人数不明の店は「人数要確認」として残します。追加リクエスト、追加 Worker、DB 起動はありません。営業時間・定休日・料理は確認できた公開情報を掲載し、未確認は明示します。ホテルは表示中の部屋の食事定員だけでフィルター判定し、スクール・シアター形式や総席数を転用しません。2027年の空席・営業・料金や同一宴会の受入可否を保証せず、公式関連イベント・予約済み店舗として扱いません。座標未検証の飲食店は地図に追加していません。

`npm test` は ERB と JSON の一致を検証し、`tests/summary.mjs` は Chromium/WebKit のデスクトップ・モバイル幅で人数フィルター、未確認表示、出典リンク、スクロール時の Worker 解放維持を検証します。Linux WebKit の成功は iPhone 実機確認ではありません。


## 過去RubyKaigi・ノベルティ

`db/data/editions.json` と `db/data/novelties.json` は2026年10月16日に出典を確認したアーカイブです。2016〜2026年の12記録（2020年の現地開催中止とTakeoutを別記録）を掲載。都市・会場・日程・プログラム・公式資料と、34件のノベルティ・記念品の実例をまとめています。全開催年・全配布物を網羅する一覧ではありません。

- 2020年の松本での現地開催中止、2020・2021年のオンライン開催、2022年の現地・オンライン併用を区別します
- 同じ年に複数の記録があるため、開催記録には固有の `id` を持たせます
- ノベルティは運営・制作者・調達担当者・配布担当者の一次資料を優先。2026年のステッカー2種は、参加者の受領記録と明示しています
- 「制作が確認できる」ことと「全員に配った」ことは別です。配布対象・役割別・数量限定・達成条件・スポンサー品を各項目に明示し、未確認の数量や対象を補いません
- 公式のNovelties／Goodiesページにあるショップやデジタル素材は「販売・デジタル資料」に分けます。現在の販売・在庫を保証せず、無料配布とみなしません
- 写真は転載せず、全項目に出典へのリンクを置きます。2023年の調達記事はブログトップで同記事の全文を確認し、恒久記事URLを掲載しています
- 「運営の読み方」は公開された実施例と、このガイドの提案を分けます。2027年の決定事項ではありません

同じRailsモデルから `/archives` のHTMLと `/archives.json` の開催・ノベルティ・参考資料を返します。新しいWorker・DB・外部リクエストは増やしません。`tests/summary-node.mjs` はデータと描画の一致、固有ID、年の並び、出典、配布区分を検証。`tests/summary.mjs` はデスクトップ・モバイルの表示、ページ内リンク、直接アクセスと再読み込みを既存のChromium/WebKit検証に含めています。

### アーカイブの画像

`db/data/archive_photos.json` が画像の原URL・出典ページ・権利者・ライセンス・確認先・変更内容を保持します。4点を `public/images/archives/` に原画像のまま保存し、表示サイズだけ調整しています。トリミングや加工はしません。

- 函館アリーナの実写写真：ITO Yosei / 伊藤製作所、CC BY 4.0
- Takeout 2021の販売グッズ紹介画像：RubyKaigi 2021 Team、CC BY 3.0。合成の紹介画像であり、無料配布の実写記録ではありません
- 2024・2026のネックストラップ案内画像：各年のRubyKaigi Team、CC BY 4.0。公式の説明パネルであり、実写写真とは区別します

画像の横と拡大表示に、権利者・出典・ライセンスを表示します。出典のクレジットは主催者による本サイトの承認を意味しません。再利用の許可を確認できなかった制作記事の写真は転載・ホットリンクせず、「写真・制作記録を見る」で元記事へ案内します。

HTMLのカードに配布区分と対象を残し、長い制作記録は開閉式にしています。画像拡大はブラウザ標準のdialogを使い、Escape・閉じるボタン・背景クリックで閉じ、元のボタンへフォーカスを戻します。戻る／進むやページ移動では拡大を解除します。画像は同一サイト内の静的ファイルだけを読み込み、追加のRailsリクエストやWorkerは起動しません。
